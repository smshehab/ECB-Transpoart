# Firestore Schema

All timestamps should be server timestamps. IDs are generated by Firestore or provisioned by administrators. Do not put custom role claims in client-editable profile fields.

- `users/{uid}`: `displayName`, `email`, optional `photoUrl`, `createdAt`, `updatedAt`.
- `buses/{busId}`: `name`, `registrationNumber`, `capacity`, `status`, `createdAt`, `updatedAt`.
- `drivers/{driverId}`: `displayName`, `email`, `assignedBusId`, `status`, `createdAt`, `updatedAt`. The ID should match the Firebase Auth UID when using `owns(driverId)` rules.
- `routes/{routeId}`: `name`, `routeCode`, `origin`, `destination`, optional route geometry, `createdAt`, `updatedAt`.
- `routes/{routeId}/stops/{stopId}`: `name`, `latitude`, `longitude`, `sequence`, optional `address`.
- `schedules/{scheduleId}`: `routeId`, `busId`, `departureTime`, `daysOfWeek`, `status`, timestamps.
- `trips/{tripId}`: `driverId`, `busId`, `routeId`, `routeName`, `status`, `startedAt`, `completedAt`, `updatedAt`.
- `announcements/{announcementId}`: `name` or `title`, `description` or `body`, audience metadata, timestamps.
- `notifications/{notificationId}`: `userId`, `title`, `body`, `readAt`, `createdAt`.
- `users/{uid}/notification_tokens/{tokenId}`: FCM `token`, `platform`, `updatedAt`.
- `app_settings/{settingId}`: administrator-managed settings.

The admin CRUD foundation currently stores a generic `name` plus timestamps for its editable collections. Expand forms and validation to the complete collection contracts before production data entry. Composite indexes are listed in `firebase/firestore.indexes.json`.
